# Ionic Quiz

A mobile-friendly math quiz application built with AngularJS and Ionic that challenges users to answer 20 math questions correctly and then provides a performance summary.

## Description

Ionic Quiz is a lightweight, responsive quiz application designed to deliver a smooth mobile experience. Built using AngularJS and the Ionic framework, the app presents users with simple math problems one at a time and tracks their progress

### Features
- Mobile-friendly responsive design using Ionic
- Randomly generated simple math questions
- Progress tracking toward 20 correct answers
- End-of-quiz performance summary

## Getting Started

### Dependencies

* Node.js
* Ionic CLI
* AngularJS (included via project dependencies)

### Installing
1. Clone the repository
2. Navigate to the project directory
3. Install dependencies:
   ```
   npm install
   ```
4. Run the application:
   ```
   npn start
   ```
5. Open in a browser or emulator to test the mobile interface
